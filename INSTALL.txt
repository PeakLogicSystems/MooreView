MooreVIEW Cloud — install bundle
================================

Targets: Debian 11/12 or Ubuntu 22.04/24.04 on
  - Single-board computers (arm64, e.g. Raspberry Pi OS 64-bit)
  - DigitalOcean bare metal or droplets (amd64)

Requirements: >=2 GB RAM, 64-bit CPU (arm64 or amd64). 32-bit armhf is not supported (MongoDB 7).

Quick install
-------------

1. Copy this archive to the host:

     scp mooreview-cloud-*.tgz root@<host>:/tmp/

2. SSH in and extract to /home/mooreview:

     ssh root@<host>
     mkdir -p /home/mooreview
     tar xzf /tmp/mooreview-cloud-*.tgz -C /home/mooreview --strip-components=1

3. Run the bootstrap script (installs Node 20, MongoDB 7, Mosquitto, systemd):

     export MOOREVIEW_SOURCE=/home/mooreview
     export MOOREVIEW_INSTALL_DIR=/home/mooreview
     bash /home/mooreview/deploy/cloud/debian/install.sh

4. Set MQTT password in /etc/mooreview/env (MOSQUITTO_PASS), then re-run install.sh.

5. Open firewall if needed:

     ufw allow OpenSSH
     ufw allow 3090/tcp
     ufw allow 1883/tcp
     ufw enable

6. Verify:

     curl -s http://127.0.0.1:3090/health
     systemctl status mongod mosquitto mooreview

Full guide: deploy/cloud/debian/README-debian.md

Services: mongod (localhost), mosquitto (1883), mooreview (3090)
