MooreVIEW Cloud Studio — WinSCP / tarball install
=================================================

Full Cloud Studio on the SaaS droplet (port 3100): ST, Projects, HMI, Drivers,
Historian, Training — plus Sites & remote cameras via site agents.

This is not a headless API-only page. Home URL serves the Studio dashboard.

1. Upload mooreview-cloud-*.tgz to /tmp/ on the droplet (WinSCP or scp).

2. SSH as root and extract:

   mkdir -p /home/mooreview
   tar xzf /tmp/mooreview-cloud-*.tgz -C /home/mooreview --strip-components=1

3. Install:

   export MOOREVIEW_SOURCE=/home/mooreview
   export MOOREVIEW_INSTALL_DIR=/home/mooreview
   sed -i 's/\r$//' /home/mooreview/deploy/cloud/debian/install-saas.sh
   bash /home/mooreview/deploy/cloud/debian/install-saas.sh

4. Verify:

   curl -s http://127.0.0.1:3100/health
   # expect: "deployment":"cloud","studio":true

   curl -sI http://127.0.0.1:3100/ | head -5
   # expect HTML (dashboard), not plain-text SaaS stub

5. Open https://mooreview.io/  (nginx must proxy to 127.0.0.1:3100)

   Sign in (seeded): Organization ID demo / operator@demo.local / demo
   Platform admin: admin@demo.local / ChangeMeAdmin!

   Full Studio: ST, Projects, HMI, Drivers…
   Tools → Sites / Devices / Assets / People / CMMS / Tenants (admin)

Data: /var/lib/mooreview
Env:   /etc/mooreview/saas.env  (PORT=3100, MOOREVIEW_DEPLOYMENT=cloud)
