MooreVIEW IOT-LINK generic appliance — install checklist
=========================================================

1. Order IOT-LINK with FARS4 + FBRS4 (dual RS-485) as needed for your field buses.
2. Transfer bundle to /opt/mooreview (see README-generic.md).
3. cp deploy/iot-link/.env.generic.example /etc/mooreview/env
4. Verify MOOREVIEW_RS485_PORT_A/B match ls -l /dev/ttyLP* on the gateway.
5. bash deploy/iot-link/install-generic.sh
6. Open http://<ip>:3090 — blank workspace; add ST program, drivers, HMI in Studio.
7. Optional MQTT: uncomment MOOREVIEW_MQTT_* in env, set MOSQUITTO_PASS, restart service.
8. Optional cloud uplink: System setup → Cloud remote.

Health: curl -s http://127.0.0.1:3090/health
Logs:   journalctl -u mooreview-iot-link-generic -f
Re-seed: node deploy/iot-link/seed-generic-config.js --force

Pool controller build: deploy/iot-link/install.sh (see README.md)
