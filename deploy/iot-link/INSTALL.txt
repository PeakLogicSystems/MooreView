MooreVIEW IOT-LINK pool controller — install checklist
========================================================

1. Order IOT-LINK with FARS4 + FBRS4 (dual RS-485) and DIO if needed.
2. Transfer bundle to /opt/mooreview (see README.md).
3. cp deploy/iot-link/.env.example /etc/mooreview/env
4. Set MOSQUITTO_PASS and verify MOOREVIEW_RS485_PORT_A/B.
5. bash deploy/iot-link/install.sh
6. Open http://<ip>:3090 — pool overview HMI.
7. Pair Opta: firmware MQTT → same broker/credentials; update opta_mqtt_st deviceId.
8. Wire PORT A → Speck pump, PORT B → Pentair or Modbus probes.
9. Optional: System setup → Cloud remote for telemetry uplink.

Health: curl -s http://127.0.0.1:3090/health
Logs:   journalctl -u mooreview-iot-link -f
Re-seed: node deploy/iot-link/seed-pool-config.js --force
