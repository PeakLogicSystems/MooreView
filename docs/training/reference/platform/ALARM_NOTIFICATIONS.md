# Alarm notification contacts and scoped assignment

See the canonical guide: [ALARM_NOTIFICATIONS.md](../../../ALARM_NOTIFICATIONS.md)

Training summary:

- **Cloud:** **People** → Edit user → **Alarm assignment** checkbox + Sites / Devices / Assets multi-select
- **Appliance:** **Alarms → Notification users…** → same scope model
- **Default:** All sites, devices & assets (checkbox checked)
- **Scoped:** Uncheck **All** and pick sites, devices, and/or assets
